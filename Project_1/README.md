# Project 1: Creating a Personal Web Site

The purpose of this project is to practice writing basic web pages with HTML and CSS and deploy them. To write two static web pages and one or more style sheets. The first web page is your UMD personal home page. The second web page is your CIS 525 course page, where you will post your finished projects.
